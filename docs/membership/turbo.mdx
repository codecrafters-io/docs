A CodeCrafters membership gives you Turbo priority for every test run, including extension stages.

## What are turbo test runs?

Turbo test runs get priority on our test runners, reducing the time you spend waiting for a run to start.

During high demand, non-Turbo runs may wait in a queue. Turbo doesn't change your code or guarantee a particular execution time.

All base-stage runs receive Turbo priority, even without a membership. Some extension-stage runs also receive Turbo without a membership; membership guarantees it for every run.

## How do I know if my test run is a turbo test run?

When your test runners are ready, a Turbo run shows this message near the start of the output:
